# Ablaze 项目部署指南

## 项目概述

Ablaze 是一个基于 Spring Boot 的博客系统，支持文章发布、用户管理、支付功能等。本指南将帮助学生完成完整的项目部署。

## 系统架构

- **后端**: Spring Boot + MyBatis-Plus + MySQL + Redis + Elasticsearch
- **数据库**: MySQL 8.0+
- **缓存**: Redis 6.0+
- **搜索引擎**: Elasticsearch 7.x
- **消息队列**: RabbitMQ
- **Web服务器**: Nginx (可选)

## 环境要求

- **操作系统**: Windows 10/11, Linux, macOS
- **Java**: JDK 8 或 JDK 11
- **Maven**: 3.6+
- **MySQL**: 8.0+
- **Redis**: 6.0+

## 第一步：安装 Java 环境

### Windows 系统

1. **下载 JDK**
   - 访问 [Oracle JDK 下载页面](https://www.oracle.com/java/technologies/downloads/)
   - 下载 JDK 8 或 JDK 11 Windows 版本

2. **安装 JDK**
   ```bash
   # 安装完成后，配置环境变量
   # 系统变量 -> 新建
   JAVA_HOME = C:\Program Files\Java\jdk-11.0.x
   
   # Path 变量中添加
   %JAVA_HOME%\bin
   ```

3. **验证安装**
   ```bash
   java -version
   javac -version
   ```

### Linux 系统

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install openjdk-11-jdk

# CentOS/RHEL
sudo yum install java-11-openjdk-devel

# 验证安装
java -version
```

```bash
# CentOS/RHEL
sudo yum install maven

# 验证安装
mvn -version
```

## 第三步：安装 MySQL 数据库

### Windows 系统

1. **下载 MySQL**
   - 访问 [MySQL 官网](https://dev.mysql.com/downloads/mysql/)
   - 下载 MySQL Community Server 8.0

2. **安装 MySQL**
   - 运行安装程序
   - 选择 "Server only" 或 "Developer Default"
   - 设置 root 密码（建议：`janx123666land`）
   - 配置端口：3306

3. **启动 MySQL 服务**
   ```bash
   # 以管理员身份运行命令提示符
   net start mysql80
   ```

### Linux 系统

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install mysql-server

# 启动 MySQL
sudo systemctl start mysql
sudo systemctl enable mysql

# 安全配置
sudo mysql_secure_installation

# CentOS/RHEL
sudo yum install mysql-server
sudo systemctl start mysqld
sudo systemctl enable mysqld
```

### 创建数据库和用户

```sql
-- 连接到 MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE ablaze CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户
CREATE USER 'ablaze'@'localhost' IDENTIFIED BY 'janx123666land';
CREATE USER 'ablaze'@'%' IDENTIFIED BY 'janx123666land';

-- 授权
GRANT ALL PRIVILEGES ON ablaze.* TO 'ablaze'@'localhost';
GRANT ALL PRIVILEGES ON ablaze.* TO 'ablaze'@'%';

-- 刷新权限
FLUSH PRIVILEGES;

-- 退出
EXIT;
```

## 第四步：安装 Redis

### Windows 系统

1. **下载 Redis**
   - 访问 [Redis Windows 版本](https://github.com/microsoftarchive/redis/releases)
   - 下载 Redis-x64-x.x.x.msi

2. **安装 Redis**
   - 运行安装程序
   - 默认端口：6379
   - 勾选 "Add Redis to PATH"

3. **启动 Redis**
   ```bash
   # 启动 Redis 服务
   redis-server
   
   # 测试连接
   redis-cli
   ping
   ```

### Linux 系统

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install redis-server

# 启动 Redis
sudo systemctl start redis-server
sudo systemctl enable redis-server

# CentOS/RHEL
sudo yum install epel-release
sudo yum install redis
sudo systemctl start redis
sudo systemctl enable redis

# 测试连接
redis-cli ping
```

## 第七步：端口配置和前后端对接

### 后端端口配置

默认后端运行在 **8080** 端口，可以通过以下方式修改：

```properties
# application.properties
server.port=8080

# 或者启动时指定
java -jar ablaze-backend.jar --server.port=8081
```

### 前端配置

如果有前端项目，需要配置 API 基础路径：

```javascript
// 前端配置文件（通常在 config.js 或 .env 文件中）
const API_BASE_URL = 'http://localhost:8080'

// 或者
VUE_APP_API_URL=http://localhost:8080
REACT_APP_API_URL=http://localhost:8080
```

### 跨域配置

后端已配置跨域支持，如果需要修改允许的域名：

```java
// 在 WebConfig 或 CorsConfig 中配置
@CrossOrigin(origins = {"http://localhost:3000", "http://localhost:8081"})
```

### 常用端口说明

| 服务 | 默认端口 | 说明 |
|------|----------|------|
| 后端应用 | 8080 | Spring Boot 应用 |
| 前端应用 | 3000/8081 | React/Vue 开发服务器 |
| MySQL | 3306 | 数据库服务 |
| Redis | 6739 | 缓存服务（配置中的端口） |
| Nginx | 80/443 | Web 服务器（可选） |

## 第九步：生产环境部署（可选）

### 使用 Nginx 反向代理

```nginx
# /etc/nginx/sites-available/ablaze
server {
    listen 80;
    server_name your-domain.com;
    
    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 系统服务配置

创建 systemd 服务文件：

```bash
# /etc/systemd/system/ablaze.service
[Unit]
Description=Ablaze Backend Application
After=network.target

[Service]
Type=simple
User=ablaze
WorkingDirectory=/opt/ablaze
ExecStart=/usr/bin/java -jar ablaze-backend.jar
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable ablaze
sudo systemctl start ablaze
```

### C. 故障排除

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 应用启动失败 | 端口被占用 | 更改端口或停止占用进程 |
| 数据库连接失败 | 服务未启动/配置错误 | 检查服务状态和配置 |
| Redis 连接失败 | 密码错误/端口错误 | 验证配置参数 |
| 内存不足 | JVM 堆内存不够 | 增加 -Xmx 参数 |
| 依赖下载失败 | 网络问题 | 配置 Maven 镜像源 |

## 总结

完成以上步骤后，你应该能够成功部署并运行 Ablaze 项目。记住以下关键点：

1. **确保所有服务正常启动**：MySQL、Redis
2. **检查配置文件**：数据库连接、Redis 配置
3. **验证端口配置**：避免端口冲突
4. **查看日志**：遇到问题时查看应用日志
5. **逐步调试**：从简单配置开始，逐步添加功能

如果遇到问题，请检查：
- 服务是否正常启动
- 配置文件是否正确
- 网络连接是否正常
- 日志中的错误信息
